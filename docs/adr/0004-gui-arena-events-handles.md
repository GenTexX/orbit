# GUI framework: arena-stored widget tree, event queue, imperative handles

The custom retained GUI stores widgets in an arena keyed by typed IDs (no pointers, no Rc<RefCell>). Input produces events that bubble up the tree into a queue; application code drains the queue each frame, mutates its own state, and updates widgets imperatively through handles. We rejected Elm-style view-diffing (requires building a reconciler; diffing large editor UIs contradicts the lightweight/snappy goal) and reactive data-binding (signals and subscription lifetimes in Rust are a research project of their own). Accepted cost: app state and widget state are synced manually. The GUI crate is independent of the Engine - it outputs a draw list, and a separate adapter crate renders that with wgpu - so it stays reusable outside Orbit.
