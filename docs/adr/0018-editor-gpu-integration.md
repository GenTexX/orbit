# The editor shares one wgpu device; the engine renders the scene into a texture the GUI composites

The editor (`atlas`) creates a single wgpu device and queue at startup and hands them to both renderers - photon (the scene) and aurora-wgpu (the chrome) - so both draw on the same device. photon renders the scene into an offscreen, sampleable texture; Aurora emits a new high-level `Image` draw command that references that texture by an opaque handle (Aurora still names no wgpu type, per ADR 0015), and aurora-wgpu resolves the handle and samples the texture into the viewport panel - so the viewport is just another widget showing a texture. Selection uses GPU picking: a second pass renders node ids into an offscreen buffer, and the pixel under the cursor is read back to identify the clicked node. The shared bootstrap (instance, adapter, device, queue, and the validation policy) moves into a small neutral crate that photon, aurora-wgpu, and atlas all depend on; neither renderer depends on the other.

We rejected two independent devices bridged by CPU readback (photon renders headless, the editor re-uploads the pixels to Aurora each frame): simplest, but a per-frame GPU-to-CPU-to-GPU round-trip we would tear out for Milestone 5's live Play - throwaway transport. We rejected compositing by carving a hole in Aurora's surface and letting photon render into that sub-rectangle: it pins the viewport under the UI and blocks drawing overlays (selection, gizmos) on top of it. We rejected making aurora-wgpu borrow photon's device directly: Aurora is engine-independent and must not depend on photon, so the shared context lives in a neutral crate.

This buys one device (less VRAM, no cross-device copies), a viewport that is an ordinary Aurora widget, and the zero-copy path Play needs later - built once. It confines wgpu to the two rendering backends plus the editor's GPU bootstrap, never the engine or model logic, extending ADR 0001's spirit. Accepted cost: an upfront device-sharing refactor of both renderers and a new shared crate, taken on now instead of after M3.
